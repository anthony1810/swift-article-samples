# swift-article-samples

[![Tests](https://github.com/anthony1810/swift-article-samples/actions/workflows/test.yml/badge.svg?branch=main)](https://github.com/anthony1810/swift-article-samples/actions/workflows/test.yml)

Companion code for articles on Swift and iOS engineering.

Each sample is a self-contained Swift Package. Open the folder in Xcode (File → Open → pick the folder containing `Package.swift`) or run `swift test` from the folder.
